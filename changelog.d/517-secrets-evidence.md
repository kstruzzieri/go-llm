### Added — Secrets accuracy and workflow evidence, interceptor census (#517)

- `docs/security/secrets-evidence.md`: a generated report on `interceptor.Secrets` as shipped. It covers accuracy by kind, carrier and hook from a classified case table, with every miss listed by case and lookalikes, fixtures and coverage gaps reported apart; the Secrets side of the interceptor census, by observation and by file; a workflow table that runs Golem's real orchestrator and tools under the always-on guards with and without Secrets; and the evaluation of the six Secrets default gates. The recorded outcome is that Secrets stays opt-in: on ordinary benign files in both local census strata it blocks more than the 1 in 100 observations the unnecessary-block budget allows, a secret-shaped test fixture in the model's own write arguments ends the run, and a default flip needs #518 first. A regeneration test keeps the report in step with its inputs. No live credentials; generated fixtures minimize committed secret-shaped material; GitHub enforcement is verified separately.
- `llm-bench -interceptor-census` (with `-census-manifest`, `-census-root` and `-census-out`, which are refused without it): a deterministic, model-free census of interceptor findings on benign files rendered through Golem's production tools (`read_file`, `search`, `run_command`, `command_tail`, the verifier, an MCP server and mixed-context assembly). It checks every file against a sha256 manifest, records each interceptor's findings once and derives the outcome for the guards-only, guards+detectors, guards+Secrets and full arms. `docs/llm/census/` holds the manifest and the committed aggregate results for this repository and the Go source tree; the README describes how to fetch the trees and reproduce the results.
- `internal/secretscan/secrettest`: the versioned Secrets case table and its deterministic generators, which expand secret-shaped values at test time so that no committed artifact carries one; a test scans the committed table, results, report, census README and the #517 test sources to enforce it.
